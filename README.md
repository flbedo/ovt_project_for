Сайт создан на фреймворке Django (ибо мне так комфортнее и понятнее). 
Для запуска сайта (что логично) нужно в venv установить django (pip install django)
Для запуска сайта нужно прописать команду: python3 manage.py runserver
Основая страница не прописана, поэтому перейдите на http://127.0.0.1:8000/index/
