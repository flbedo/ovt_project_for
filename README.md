# Краткое описание

Данный мини-проект представляет собой легковесное веб-приложение на Python (Flask), предназначенное для управления системным статусом руки

## Запуск

1. Убедиться что установлен python3
2. Установите зависимости: ```pip install flask psutil pytz```
4. В командной строке прописать: ```python main.py```

## Управление

Управление можно использовать браузер, или PowerShell.

1. Посмотреть текущий статус: http://127.0.0.1:3000/status
2. Уставновить статус в ON: http://127.0.0.1:3000/on
3. Установить статус в OFF: http://127.0.0.1:3000/off
4. Посмотреть текущий статус (без оформления): http://localhost:3000/api/status

С помощью PowerShell (для обхода назойливого подтверждения curl в cmd):
1. ```iwr -UseBasicParsing http://127.0.0.1:8000/api/status```
2. ```iwr -UseBasicParsing http://127.0.0.1:8000/on```
3. ```iwr -UseBasicParsing http://127.0.0.1:8000/off```
